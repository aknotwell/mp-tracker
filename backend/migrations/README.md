# Database migrations

Alembic owns the persistent database schema. Run commands from `backend/`:

```powershell
python -m alembic upgrade head
```

Create a revision only after changing the SQLAlchemy models:

```powershell
python -m alembic revision --autogenerate -m "describe the schema change"
```

Always review autogenerated revisions before applying them. SQLite table alterations
use Alembic batch mode, which may copy data through a temporary replacement table.
